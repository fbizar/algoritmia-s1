#  Asistente de taquilla Rueda Libre v1.0
Un conjunto de algoritmos en PSeInt que cotiza alquileres y recorridos, aplica las tarifas y los descuentos del negocio, valida los datos de una reserva con las mismas reglas del formulario que construyes en HTML, atiende a varios clientes seguidos y entrega
el cierre de caja del día.
